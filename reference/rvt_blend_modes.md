# Blend modes

The thirteen layer blending modes
[`rvt_blend()`](https://wiesehahn.github.io/rvtr/reference/rvt_blend.md)
understands, named as they are in QGIS so the vocabulary carries over.

## Usage

``` r
rvt_blend_modes
```

## Format

Character vector of length 13.

## See also

[`rvt_blend()`](https://wiesehahn.github.io/rvtr/reference/rvt_blend.md)

## Examples

``` r
rvt_blend_modes
#>  [1] "normal"     "lighten"    "darken"     "multiply"   "screen"    
#>  [6] "addition"   "subtract"   "difference" "overlay"    "hard_light"
#> [11] "dodge"      "burn"       "soft_light"
```
